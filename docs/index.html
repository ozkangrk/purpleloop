How it works

Five stages. One provable pipeline.

Every stage writes to the SHA256 hash chain before the next one runs. If any link breaks, the run fails closed.

1Scope Gate

A signed scope contract defines targets; anything outside it is denied with SCOPE_DENY before a single packet leaves.

2Recon

Scoped enumeration collects raw candidate findings — every request logged to the hash chain.

3Validator

Deterministic re-testing confirms or discards each finding; only CONFIRMED findings survive.

4Safe-mode Exploit

Non-destructive proofs demonstrate real exploitability with captured evidence — no collateral damage.

5Attack Paths & Report

Confirmed findings are chained into attack paths and mapped to a Turkish KVKK/ISO 27001/SOC 2 management report.

Scope Contract

Targets, ports and methods are declared up front. Out-of-scope requests are rejected with SCOPE_DENY — fail-closed by design, not by configuration.

Trust architecture

The model advises.
The harness decides.

LLM agents are powerful analysts and unreliable executioners. PurpleLoop uses them only as advisors inside a deterministic control plane that owns every decision, every request and every log line.

AI
Agent — advisory role

Proposes findings, hypotheses and next steps. Cannot send traffic, mutate state, or write to the audit log.

PL
Harness — control plane

Enforces the scope contract, runs deterministic validation, executes safe-mode proofs, and owns the hash chain. If the harness says no, nothing moves.

⛓
Evidence — immutable

Every decision lands in the SHA256 chain. You can independently verify what ran, when, and against what — long after the run.

Continuous monitoring

Point-in-time scans age in minutes.
Deltas age never.

1
Scan

A cron-scheduled cycle re-runs the validated pipeline under the same scope contract — every request still fail-closed.

2
Compare

The cycle's confirmed findings are diffed against the previous state; only NEW and RESOLVED items are kept.

3
Alert

Critical changes — a leaked secret, a new exposure — fire an alert line the same cycle, not in next quarter's report.
